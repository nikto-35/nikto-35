# Nikto — Who I Am

Responsive personal website for desktop and mobile.

## Discord presence
The site uses Lanyard with Discord User ID `1393852466495356946` to display Online / AFK / Do Not Disturb / Offline status.

For Lanyard to provide a user's live presence, that Discord account needs to be visible to Lanyard (normally by sharing a server with the Lanyard bot). If it cannot see the account, the page safely shows Offline.

No Discord password, token, or private credential is used.

## Deploy
Upload the contents of this folder to the root of your GitHub Pages repository. Keep `assets/profile.jpg` in the same relative location.

Music is intentionally not included yet.
